## איך מפרסמים את האתר (חינם, ב-GitHub Pages)

1. היכנסו להגדרות הרפוזיטורי בגיטהאב: **Settings → Pages**
2. תחת **Build and deployment**: בחרו Source = `Deploy from a branch`
3. בחרו Branch = הענף הראשי, Folder = **`/docs`** ולחצו Save
4. תוך דקות האתר יעלה לכתובת `https://<username>.github.io/<repo>/`

### חיבור הדומיין mivnedarom.co.il

1. בהגדרות Pages, בשדה **Custom domain** הזינו: `www.mivnedarom.co.il` ולחצו Save
2. אצל ספק הדומיין שלכם (מי שמנהל את ה-DNS), הגדירו:
   - רשומת **CNAME** עבור `www` שמצביעה אל `<username>.github.io`
   - 4 רשומות **A** עבור הדומיין הראשי (`mivnedarom.co.il`):
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
3. סמנו **Enforce HTTPS** (תעודת SSL חינם אוטומטית)
4. רק אחרי שהאתר החדש באוויר ונבדק — בטלו את המנוי לפלטפורמה הישנה 🎉

> אפשרויות אירוח חינמיות נוספות: Netlify או Cloudflare Pages — פשוט מצביעים על תיקיית `docs/`.

## איך עורכים תוכן?

1. ערכו את הקבצים ב-`website/content/` (טקסטים, מוצרים, שאלות נפוצות) או את התבניות ב-`website/templates/`
2. הריצו מחדש את הבנייה:
   ```bash
   cd website
   pip install jinja2   # פעם ראשונה בלבד
   python3 build.py
   ```
3. עשו commit ו-push — האתר יתעדכן אוטומטית
